# IMU 与双随动轮平面定位概览

本文件介绍当前工程的定位结构、坐标和使用方法。公式及标定过程见 [算法与标定详细说明](planar_localization_detailed_study.md)，配置与验收状态见 [工程收尾说明](project_handover.md)。

## 硬件和输出

| 项目 | 当前配置 |
| --- | --- |
| 主控与系统 | STM32F407VET6、FreeRTOS |
| IMU | Epson M-G354PDH0，SPI3，DRDY，500 Hz |
| 前后测量轮 | MT6826S，SPI1，PA4 软件片选，1 kHz DMA |
| 左右测量轮 | MT6826S，SPI2，PB12 软件片选，1 kHz DMA |
| 测量轮 | 独立贴地的从动全向轮，两轮名义直径 58 mm |
| 位姿 | 底盘中心 X、Y，单位 mm；相对初始朝向的 Yaw，单位 ° |
| 串口 | USART2，PD5/PD6，115200、8N1，TX DMA，标称 100 Hz |
| 屏幕 | SSD1306 128×64，I2C3，PA8/PC9，500 ms 刷新 |

测量轮直接读取 SPI 绝对单圈角度，当前每圈使用 32768 个计数。“两轮正交”指滚动测量方向近似垂直，不要求使用 AB 相接口。

## 处理流程

1. 开机保持静止。IMU 完成初始化，丢弃 50 个过渡样本，再采集连续 1000 点计算启动零偏和各轴噪声方差，正常约 3 秒就绪。
2. 三轴角速度分别进行新息自适应卡尔曼滤波，扣除启动零偏、可选温度项和运行中剩余零偏。
3. 联合角速度、加速度与两轮状态判断静止；确认静止后限速更新剩余零偏。
4. 应用三轴 0.3 °/s 暂用死区，使用 Heun 二阶 Runge-Kutta 方法积分四元数，归一化后输出 ZXY 姿态角。
5. 两路编码器展开为累计计数。以有效 IMU 时间点为公共端点，将每轮历史计数插值到相同时刻。
6. 累计计数差换算为滚动距离，利用方向矩阵求出两条滚动直线交点的平移，再补偿交点到底盘中心的转动偏置。
7. 以区间中点航向将位移转入初始世界坐标系，累加 X、Y，再发布给串口和屏幕。

位置来自测量轮滚动距离；加速度用于静止及标定判据。自适应 KF 用于角速度降噪，位姿由几何模型与航向积分得到，当前没有建立完整的位姿 EKF。

## 坐标和名义参数

俯视底盘，+X 向前、+Y 向左，逆时针航向为正。世界坐标原点取首个有效公共端点的底盘中心，+X 沿该时刻底盘朝向。此前的运动不计入轨迹。

| 参数 | 当前值 |
| --- | --- |
| SPI1 滚动正方向角 | 相对底盘 +X 为 0° |
| SPI2 滚动正方向角 | 相对底盘 +X 为 90° |
| 两轮方向符号 | 暂定均为 +1 |
| 编码器圈数 / 轮子圈数 | 均为 1 |
| 滚动直线交点 C 相对底盘中心 O | `cx=-20 mm, cy=+20 mm`，后方 20 mm、左方 20 mm |

角度测量沿轮子的滚动方向，不沿轮轴。底盘驱动轮以 45° 安装不会自动增加固定坐标旋转。实际装车后应重新测量滚动方向、轮径和交点偏置。

## 关键公式

```text
ds_i = direction_i * pi * D_i / (32768 * gear_ratio_i) * delta_counts_i
H = [[cos(alpha_1), sin(alpha_1)],
     [cos(alpha_2), sin(alpha_2)]]
[dx_C, dy_C]^T = inverse(H) * [ds_1, ds_2]^T
dx_O = dx_C + cy*dtheta
dy_O = dy_C - cx*dtheta
theta_mid = theta_previous + dtheta/2
X += cos(theta_mid)*dx_O - sin(theta_mid)*dy_O
Y += sin(theta_mid)*dx_O + cos(theta_mid)*dy_O
```

`dtheta` 是处理回绕后的航向增量，公式中使用弧度。方向接近平行时矩阵病态，当前拒绝 `abs(det(H)) < 0.1` 的配置。

## 同步和有效性

三路采样共享连续运行的 TIM2 微秒时钟。IMU 记录 DRDY 时间，编码器记录采样片选时间；这不等于已消除器件内部滤波延迟。

每轮保留 32 点历史，IMU 航向队列保留 16 点。插值必须有前后样本，最大跨度为 4 ms。短暂同步问题可跳过端点，在输入连续且满足时间边界时恢复；真实输入缺失、计数重置或无法及时恢复时锁存跟踪丢失，保持最后坐标并置无效。

消费位姿时使用 `odometry_app_get_output()`；串口和屏幕共用这一接口。屏幕显示 `ODOM RUN E0` 表示最近一次显示快照有效，显示 `WAIT`、`LOST` 或 `ERROR` 时需结合串口状态及调试字段判断。

## 标定和验收顺序

1. 静止上电，等待启动标定完成。
2. 向前、向左分别移动，确认坐标及编码器计数方向。
3. 测量直线距离，分别标定两轮有效轮径。
4. 原地顺逆时针旋转，检查航向符号与底盘中心 X/Y 残差，调整安装角和交点偏置。
5. 有转台后测量正反转的已知角度、不同角速度与低速响应，再调整角速度死区。
6. 静止采集不同温度的数据，检查温漂和重复性，完成后再启用温度模型。
7. 执行矩形路线与长时静止记录，以独立距离和角度基准评估误差。

当前 0.3 °/s 死区会抑制真实慢转；温漂模型默认关闭。轮径、方向角及安装偏置仍需装车标定。相关接口和调试字段见 [姿态模块](../modules/attitude/README.md)、[里程计模块](../modules/odometry/README.md) 和 [OLED 模块](../modules/oled/README.md)。
